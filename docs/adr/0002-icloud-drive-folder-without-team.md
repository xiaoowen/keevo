# ADR-0002：iCloud 同步使用 iCloud 云盘中的普通文件夹，不绑定任何开发者团队

- **状态**：已采纳；"发布前仍需要 Keevo 自己的开发者账号"一节与决策第 3 条由 [ADR-0003](0003-no-apple-developer-team.md) 推翻
- **日期**：2026-11-18
- **修订**：[ADR-0001](0001-file-based-cloud-sync.md) 中"默认使用 Keevo 专属的 iCloud 容器"一条

## 背景

ADR-0001 选定了基于不可变文件的加密日志，并把 iCloud 专属容器（`iCloud.app.keevo`，对 Finder 隐藏）作为默认同步位置。

专属容器是受限能力，应用必须由某个 Apple 开发者团队的证书签名，并附带启用 iCloud 的描述文件；容器一经创建，就永久归属该团队。目前可用的团队都属于其他项目。

[技术验证](../spikes/2026-11-18-icloud-folder.md)表明，iCloud 云盘中的普通文件夹不需要任何证书或权限：未签名的进程就能完成写入、读取上传与下载状态、移除本地内容、按需下载、文件协调与变化监听。4 次运行全部通过。

## 决策

1. **Keevo 不使用任何现有团队**：不注册 App ID，不创建 iCloud 容器，不登记设备。
2. **M2 的 iCloud 同步位置改为 iCloud 云盘中的普通文件夹** `iCloud 云盘/Keevo/`（磁盘路径为 `~/Library/Mobile Documents/com~apple~CloudDocs/Keevo/`）。
   - 它与 Dropbox、OneDrive、Syncthing、NAS 走同一套文件夹实现。
   - 区别只在于 iCloud 的路径是已知的，可以自动发现。
3. **专属容器降为将来的可选增强**：Keevo 有了自己的开发者账号后再评估。（ADR-0003 起不再计划：Keevo 不绑定任何团队。）
   - 届时只需新增一个 `SyncStore` 实现，同步格式不变。
   - 已有用户可以从文件夹迁移到容器。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **A. iCloud 云盘普通文件夹（采纳）** | 不需要团队、证书和描述文件；已实测可行；与其他云盘共用一套实现 | 文件夹在 Finder 中可见，用户可能误删、移动或改名；变化监听只能用 FSEvents | 采纳 |
| B. 专属容器，挂在现有团队下 | 数据对 Finder 隐藏，可用 `NSMetadataQuery` | 容器永久归属其他项目的团队，日后无法迁走 | 不采纳 |
| C. 现在就为 Keevo 申请开发者账号 | 一次解决签名、公证、容器 | 需要组织主体与费用，不阻塞 M0–M1 | 推迟到正式发布前 |

## 影响

**同步设计**（已改入 `docs/sync.md` §6）：
- 变化监听：FSEvents 加定期扫描。
- 读取前先检查文件是否只在云端。
- 上传错误按错误码分级处理。

**文件夹可见带来的风险与应对**：

| 风险 | 应对 |
|---|---|
| 用户误删文件 | 由哈希链与高水位线发现，本机保留的段副本自动补写（sync.md §5） |
| 用户移动或改名文件夹 | 每次启动按已知路径与 `keevo.json` 中的账户 ID 查找；找不到时暂停同步并提示，绝不自动新建空文件夹覆盖 |
| 用户看到大量看不懂的文件 | 文件夹内放一个 `请勿修改.txt`，说明这是 Keevo 的加密同步数据 |

**发布前仍需要 Keevo 自己的开发者账号**：

> 本节已被 [ADR-0003](0003-no-apple-developer-team.md) 推翻：Keevo 不绑定任何开发者团队，下表中的功能改用替代方案或移出路线图。保留原文以便追溯。

不绑定现有团队不等于永远不需要团队。下列功能依赖团队签名，需要在正式发布前（最迟 M3）为 Keevo 申请组织类型的开发者账号。在此之前，开发构建继续使用临时签名。

| 功能 | 依赖 | 状态 |
|---|---|---|
| Developer ID 签名与公证（Gatekeeper 放行） | 团队的 Developer ID 证书 | 已确认 |
| Chrome native host 校验 Keevo 自身的签名（`spec/ipc.md` §3.1） | Keevo 的 Team ID | 已确认 |
| Touch ID 解锁（Secure Enclave 密钥存入数据保护钥匙串） | 很可能需要团队签发的钥匙串访问权限 | M1.1 验证 |
| 用 iCloud 钥匙串同步账户密钥（可选功能） | 同上 | M2 验证 |
