# Alpha 人工检查清单

自动化测试覆盖不到、需要人在真机上操作的检查，汇总自路线图 §3.3–§3.7 各节与 ADR-0003 的待验证项。是 Alpha 验收（路线图 §8 第 5 项）的一部分。

**怎么做**

- **机器**：一台系统完整性保护开启（`csrutil status` 为 enabled）、登记了指纹的 Mac。
- **安装包**：用打包产物 `scripts/package-macos.sh` 生成的 Keevo.app，不用开发构建。
- **扩展**：`scripts/build-extension.sh` 生成的 `apps/browser-extension/dist`，在 Chrome 中以开发者模式加载。
- **记录**：每项把结果填进文末的记录表，发现的问题写清楚复现步骤。
- **通过标准**：全部"通过"，或问题已修复后复查通过；不修复的问题写明理由。

**结果**（2026-11-23）：23 项全部通过。

## A. 安装与进程加固

- [x] **A1 未公证应用的首次打开**（ADR-0003 待验证）：从网页下载打包好的 Keevo.app（带隔离属性），记录 Gatekeeper 的实际提示，以及"系统设置 → 隐私与安全性 → 仍要打开"的完整步骤与系统版本。
- [x] **A2 真机上的进程加固**：`scripts/package-macos.sh --verify` 全部通过。DYLD 注入与 Library Validation 两项必须是"✓"，不能是"跳过"：CI 的运行器关闭了系统完整性保护，这两项只能在真机上验证。

## B. 账户、解锁与条目（M1.1、M1.2）

- [x] **B1 Touch ID，锁屏时**：`keevo-smoke --touch-id-locked`，按提示操作，全部通过。
- [x] **B2 Touch ID，指纹变化后**：先 `keevo-smoke --touch-id-change prepare <目录>`，在系统设置中增删一个指纹，再 `keevo-smoke --touch-id-change check <目录>`，全部通过。之后恢复原来的指纹。
- [x] **B3 "不允许截屏或屏幕共享"**：开启后逐一检查以下方式能否看到 Keevo 窗口的内容，记录哪些方式遵守这一设置：
  - ⌘⇧3、⌘⇧4、⌘⇧5 录屏；
  - QuickTime 录屏；
  - 一款会议软件的屏幕共享。
- [x] **B4 每种条目类型的基本操作**（验收标准"功能"）：8 种类型各新建一个，再依次编辑、搜索、删除、从回收站恢复。
- [x] **B5 扫描屏幕上的二维码**：编辑器中"从二维码导入一次性密码"，在系统的内容共享选择器中选择一个显示二维码的窗口，能识别并填入。

## C. 浏览器（M1.3）

- [x] **C1 Keevo.app 中各确认界面的实际操作**：
  - 配对：配对码、倒计时、到期按拒绝；
  - 第一次为某个条目在某个站点填充时的授权：60 秒到期，回车不会误放行；
  - 更新密码的确认；
  - 频率限制暂停后的确认；
  - 每次解锁后第一次"搜索全部条目"的允许。
- [x] **C2 剪贴板清除**：从弹窗复制密码，90 秒后被清除；期间另外复制了别的内容时，不会被清除。
- [x] **C3 最小权限模式下的快捷键**：不授予网站权限，在登录页按 ⌘⇧L 能填充。

## D. 开发者功能（M1.4）

- [x] **D1 CLI 与 SSH 的确认界面**：分别用 Touch ID 与主密码完成确认。
- [x] **D2 写入配置的实际效果**：
  - 写入 `~/.ssh/config` 后 `ssh` 连接能用 Keevo 的密钥；
  - 写入 Git 签名配置后，`git commit -S` 与 `git log --show-signature` 正常。
- [x] **D3 真实终端中会话键的划分**：在 iTerm2 与 Terminal 中，同一标签页内只授权一次；新标签页、新窗口重新授权。
- [x] **D4 导入有口令保护的私钥**：OpenSSH 格式的 Ed25519 私钥，输入口令后导入成功；口令错误时提示清楚。
- [x] **D5 `keevo run`**：在真实终端中，子进程的颜色输出正常，缩放窗口后子进程能收到新的尺寸。

## E. 导入导出、备份与打磨（M1.5）

- [x] **E1 应用图标**：程序坞、启动台，浅色、深色与着色外观。
- [x] **E2 泄露检查**：实际联网检查一次，结果与网络请求（只发送哈希前 5 位）符合 docs/governance.md §5。
- [x] **E3 备份与恢复**：备份到外部硬盘，在另一个空的账户目录中从备份恢复，条目与附件完整。
- [x] **E4 导入真实的导出文件**：
  - 1Password 的 1PUX；
  - Bitwarden 的 JSON，含有密码保护的；
  - 浏览器的 CSV。

- [x] **E6 快速访问**：在全屏应用中、在多个桌面之间都能唤出；快捷键与其他应用冲突时有提示。
- [x] **E7 菜单栏**：关闭主窗口后，菜单栏图标的行为与 docs/ux.md 一致。
